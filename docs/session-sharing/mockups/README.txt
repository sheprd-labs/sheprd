Sheprd — Shared sessions concept

Open index.html in a web browser to explore all three interactive views.
No server, installation, or internet connection is needed.

01-sharing-dialog.png — Owner sharing permissions and invitation dialog
02-web-view.png — Recipient viewing a session in a browser
03-app-view.png — Recipient viewing a session inside Sheprd

This is a design prototype with fictional data. Sharing, permissions,
agent actions, and invitation links are simulated. Nothing connects to
a real session. The .example invitation address is intentionally invalid.

The browser view has prototype controls in its right sidebar for changing
the access role and connection state.
