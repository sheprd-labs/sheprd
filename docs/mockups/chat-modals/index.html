DESIGN MOCKUPS · AGENT CHAT DIRECTIVES & PERSISTENT MODALS

Beyond effects: persistent modals for agents

Today agents can only play transient chat effects (:::slam, ::confetti, ::wizz) that vanish in a few seconds. Here are visual mockups for two persistent tiers: Window modals (pinned to the agent's Sheprd window) and Global "can't miss" modals (always-on-top across every app, Space, and display — e.g. blocked waiting for a YubiKey touch).

Optional CLI companion (hooks & scripts)
sheprd modal show --scope all \
  --title "Tap your YubiKey" \
  "Waiting on git push"

sheprd modal clear

Lets an agent mid-tool-call, an SSH_ASKPASS hook, or a subagent open & clear a modal explicitly.

D1 · Trigger surface

Chat directives only, or directives + CLI?

Directives (:::modal / :::urgent) work from any chat agent (even remote SSH). Adding sheprd modal show|clear also lets scripts & blocked tool calls trigger and clear deterministically.

D2 · Keyboard focus (global modal)

Should the global modal steal keyboard focus?

Keeping focus lets you finish a word in Slack/browser without accidentally dismissing the modal with Space/Enter; taking focus makes Esc/Enter work immediately.

D3 · Auto-clear lifecycle

Clear automatically when the blocker ends?

For a YubiKey touch on git push, the command finishes as soon as you tap. Auto-clearing when the agent resumes/completes (with a brief green "Done" fade) avoids stale modals.

D4 · Settings & safety guardrails

How should users control or silence modals?

Independent of Message effects (you may hate confetti but still need YubiKey modals). Respects worktree/host mute for window modals; global modals get a dedicated toggle in Settings > Chat.
