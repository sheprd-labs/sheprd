Appearance ↗

  1. Open the theme picker

    Search for themes in the command palette, or open Settings, Theme.

  2. See it before you settle

    Move through the list and the whole window changes. Try a light theme, then a dark one.

  3. Keep the one you like

    Type to filter, then press Return to keep it.

Sheprd lets you change its whole look in seconds.

Open the command palette with Command Shift P, and search for themes.

Move through the list: every theme previews live, across the whole window.

Type to filter, then press Return to keep the one you like.

It's saved, and you can change it again anytime.
