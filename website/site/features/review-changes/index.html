Review Changes

Review and commit ↗

  1. Open Review Changes

    Search for it in the command palette. It lists every file with uncommitted changes, or everything since the base branch.

  2. Note what should change

    Click a line number, describe the change and add the note. Notes go to the workspace's agent.

  3. Keep track

    Mark each file viewed once it looks right, and hide viewed files to see what is left.
