# Reuse a prompt in chat
fr: Réutiliser une consigne dans un chat

## 1
en: If you ask for the same review each week, save the prompt in Text Shortcuts.
fr: Si vous demandez la même revue chaque semaine, enregistrez votre consigne dans « Text Shortcuts ».

## 2
en: Give it a short label and write the instructions you want to reuse.
fr: Donnez-lui un nom court, puis saisissez les instructions à réutiliser.

## 3
en: Back in chat, start a draft with the file you want reviewed, then open the shortcuts beside the composer.
fr: De retour dans le chat, saisissez le nom du fichier à examiner, puis ouvrez les raccourcis à côté du champ de saisie.

## 4
en: Pick your review instructions. They’re added to your draft, ready to send together.
fr: Choisissez votre consigne de revue. Elle s’ajoute au brouillon, et vous pouvez envoyer le tout à l’agent.
