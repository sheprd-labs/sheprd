# Undo an agent’s changes
fr: Revenir en arrière après une modification

## 1
en: The forecast command has changed. To try the earlier version again, open Checkpoints from the workspace menu.
fr: La commande de prévisions a changé. Pour retrouver la version précédente, ouvrez « Checkpoints » dans le menu du projet.

## 2
en: Sheprd saves the checkout when an agent starts and finishes a turn. Pick the point just before the edit.
fr: Sheprd enregistre une copie du projet au début et à la fin de chaque tour de l’agent. Sélectionnez celle qui précède la modification.

## 3
en: Confirm the restore to put the files and the branch back where they were.
fr: Confirmez la restauration pour retrouver les fichiers et la branche dans leur état précédent.

## 4
en: Sheprd saves the state you just left, too. You can return to it from this list.
fr: Sheprd garde aussi une copie de l’état que vous venez de quitter. Vous pouvez le retrouver dans cette liste.
