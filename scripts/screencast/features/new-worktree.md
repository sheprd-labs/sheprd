# Start a branch in its own folder
fr: Ouvrir une branche dans son propre dossier

## 1
en: The forecast app needs a new output format. Open New worktree from its workspace menu.
fr: Il faut un nouveau format de sortie pour les prévisions. Dans le menu du projet, choisissez « New worktree ».

## 2
en: Enter a branch name. An existing branch keeps its history. A new branch starts from the checkout you selected.
fr: Saisissez un nom de branche. Vous pouvez reprendre une branche existante ou en créer une à partir de la branche sélectionnée.

## 3
en: Under Opens in, choose a shell or an installed agent for the first pane. Let’s open a terminal.
fr: Dans « Opens in », choisissez un terminal ou un agent installé pour le premier volet. Ici, prenons le terminal.

## 4
en: Add a note to the new checkout. The first line appears under its branch in the sidebar.
fr: Ajoutez une note au nouveau dossier de travail. Sa première ligne apparaît sous la branche dans la barre latérale.
