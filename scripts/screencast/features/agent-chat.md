# Native agent chats
fr: Des chats natifs avec vos agents

## 1
en: Sheprd runs your coding agents in native chats, beside your terminal.
fr: Sheprd fait tourner vos agents de code dans de vrais chats, à côté de votre terminal.

## 2
en: Start one with the agent button, right next to the new tab button.
fr: Lancez-en un avec le bouton d'agent, juste à côté du bouton de nouvel onglet.

## 3
en: Switch agents any time: Claude, Codex, Gemini, or any other you have installed.
fr: Changez d'agent à tout moment : Claude, Codex, Gemini, ou tout autre agent installé.

## 4
en: Ask for what you need. The agent reads your code, makes the change and runs the tests.
fr: Demandez ce qu'il vous faut. L'agent lit votre code, fait la modification et lance les tests.

## 5
en: Every step is a card: what it read, the lines it changed, and what the tests said.
fr: Chaque étape est une carte : ce qu'il a lu, les lignes modifiées, et le résultat des tests.

## 6
en: And the answer arrives formatted, ready for you to review.
fr: Et la réponse arrive mise en forme, prête à être relue.
