# Find the server behind a port
fr: Retrouver le serveur derrière un port

## 1
en: Start a local server from the forecast terminal. Its port appears beside the workspace.
fr: Lancez un serveur local depuis le terminal du projet météo. Son port apparaît à côté du projet.

## 2
en: Open the port to preview the page the server is serving.
fr: Ouvrez ce port pour afficher la page que le serveur met à disposition.

## 3
en: The Ports view shows which process owns the listener and the folder it started in.
fr: La vue « Ports » indique quel processus écoute sur ce port et depuis quel dossier il a démarré.

## 4
en: Stop the forecast server in its terminal. Its port disappears from the workspace.
fr: Arrêtez le serveur dans son terminal. Le port disparaît de la barre latérale.
