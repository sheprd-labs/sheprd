# The command palette
fr: La palette de commandes

## 1
en: Everything in Sheprd is a few keystrokes away, in the command palette.
fr: Dans Sheprd, tout est à quelques touches, dans la palette de commandes.

## 2
en: Press Command Shift P: workspaces, terminals, agents and commands, in one list.
fr: Appuyez sur Commande Majuscule P : espaces de travail, terminaux, agents et commandes, dans une seule liste.

## 3
en: Type a few letters and press Return. Here, a split beside the terminal.
fr: Tapez quelques lettres et appuyez sur Entrée. Ici, une division à côté du terminal.

## 4
en: The chips at the top narrow the list, for example to commands only.
fr: Les filtres du haut réduisent la liste, par exemple aux seules commandes.

## 5
en: Escape closes it, right where you left off.
fr: Échap la ferme, et vous reprenez là où vous en étiez.
