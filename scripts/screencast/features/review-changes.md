# Review Changes
fr: Relire les changements

## 1
en: Before you ship what an agent wrote, review it in Sheprd.
fr: Avant de livrer ce qu'un agent a écrit, relisez-le dans Sheprd.

## 2
en: Open Review Changes from the palette: every file the work touched.
fr: Ouvrez « Relire les changements » depuis la palette : chaque fichier modifié.

## 3
en: Each change sits beside the code it replaces.
fr: Chaque modification s'affiche face au code qu'elle remplace.

## 4
en: Click a line number to leave a note for the agent.
fr: Cliquez sur un numéro de ligne pour laisser une note à l'agent.

## 5
en: Then mark the file viewed, and move on to the next.
fr: Puis marquez le fichier comme vu, et passez au suivant.
