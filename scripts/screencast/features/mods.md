# Add a status bar item
fr: Ajouter un élément à la barre d’état

## 1
en: A small Luau mod can put a project tool in the status bar.
fr: Un petit module en Luau permet d’ajouter un outil à la barre d’état.

## 2
en: The manifest chooses where the mod appears. Its view defines the text you see.
fr: Le manifeste indique où le module apparaît. Sa vue définit le texte affiché.

## 3
en: Change the label and save the file. Watch the status bar update while the terminal stays open.
fr: Modifiez le libellé et enregistrez le fichier. Le texte change dans la barre d’état et le terminal reste ouvert.
