# Try two approaches to one task
fr: Essayer deux approches en parallèle

## 1
en: Open Fan out from the forecast workspace to give two agents the same task.
fr: Dans le menu du projet de prévisions, choisissez « Fan out » pour confier la même tâche à deux agents.

## 2
en: Describe the change once, then choose the agents that should try it.
fr: Décrivez la modification une seule fois, puis choisissez les agents qui vont s’en charger.

## 3
en: Start the run. Each agent gets its own branch and folder, so both can edit the same file independently.
fr: Lancez le travail. Chaque agent dispose de sa propre branche et de son propre dossier. Les deux peuvent modifier le même fichier en parallèle.

## 4
en: Open each result to compare the changes before choosing which branch to keep.
fr: Ouvrez les résultats pour comparer les modifications avant de choisir la branche à conserver.
