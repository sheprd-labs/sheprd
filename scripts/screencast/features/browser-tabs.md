# Send feedback on a preview
fr: Annoter un aperçu pour l’agent

## 1
en: Ask for a preview to see the forecast page beside the chat.
fr: Demandez un aperçu pour voir la page de prévisions à côté du chat.

## 2
en: Choose Annotate, then click the button you want to change.
fr: Choisissez « Annotate », puis cliquez sur le bouton à modifier.

## 3
en: Describe the change and add the note. The number on the page marks the exact button.
fr: Décrivez la modification et ajoutez la note. Le numéro sur la page repère le bouton que vous avez choisi.

## 4
en: Send the note to the agent that opened the page. It gets your words along with the element you picked.
fr: Envoyez la note à l’agent qui a ouvert la page. Il reçoit votre demande avec l’élément que vous avez désigné.

## 5
en: Here the button turns green on reload. Close the preview to return to the conversation.
fr: Ici, le bouton devient vert au rechargement. Fermez l’aperçu pour revenir à la conversation.
