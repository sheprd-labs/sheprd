# Two panes, one tab
fr: Deux volets dans un onglet

## 1
en: Keep the forecast output in view while you work in another shell.
fr: Gardez les prévisions sous les yeux pendant que vous travaillez dans un autre terminal.

## 2
en: Press Command D to split the tab. Each side has its own terminal.
fr: Appuyez sur Commande D pour diviser l’onglet. Chaque volet dispose de son propre terminal.

## 3
en: Open the tab layout setting. Classic gives each pane a header. Pills puts a small label in the corner.
fr: Ouvrez le réglage de présentation des onglets. « Classic » ajoute un en-tête à chaque volet. « Pills » place une petite étiquette dans le coin.

## 4
en: Choose Curved to see the rounded panes. Close the second shell when you want the full width again.
fr: Choisissez « Curved » pour arrondir les volets. Fermez le deuxième terminal pour retrouver toute la largeur de la fenêtre.
